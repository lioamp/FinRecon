# FinRecon

Financial Data Reconciliation and Validation System

## Overview

FinRecon is a Python-based application designed
to compare financial reports from multiple systems,
identify discrepancies, validate transaction records,
and generate reconciliation reports.

## Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Streamlit
- Plotly
- Pytest

## Project Status

Currently under development.

## Objectives

- Automate financial report reconciliation.
- Identify inconsistent and missing transactions.
- Perform data validation and cleaning.
- Generate analytical reports.
- Provide an interactive dashboard.
